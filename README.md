# job-application-agent

Agent pour automatiser la recherche et la candidature à des offres d'emploi.

## Structure

```
job-application-agent/
├── README.md
├── .gitignore
├── profile/     # Infos personnelles, compétences, préférences de recherche
├── cv/          # CV et lettres de motivation (modèles et versions générées)
├── browser/     # Automatisation du navigateur (connexion, remplissage de formulaires)
├── workflows/   # Enchaînements d'étapes : recherche → tri → candidature
└── examples/    # Exemples d'offres, de profils et de candidatures
```
